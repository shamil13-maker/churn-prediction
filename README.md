## 📌 Описание проекта
Этот проект представляет собой **решение задачи классификации** для прогнозирования оттока клиентов телеком-компании. 
Модель позволяет выявить клиентов, которые с высокой вероятностью могут уйти к конкуренту, что помогает бизнесу своевременно предпринять меры по удержанию.

**Ключевая метрика:** ROC-AUC = 0.86

## 📊 Данные
В проекте используется публичный датасет **Telco Customer Churn** с платформы Kaggle.
- **Количество записей:** 7043
- **Признаки:** 20 (стаж, тариф, тип контракта, доп. услуги и др.)
- **Целевая переменная:** Churn (Yes/No)

## 🔬 Методология
1. **EDA (Исследовательский анализ):** Выявлены ключевые факторы: стаж клиента и тип контракта.
2. **Предобработка:** Масштабирование признаков, One-Hot Encoding, создание новых фич (среднемесячный платеж).
3. **Модели:** Обучены 3 модели — Logistic Regression, Random Forest, XGBoost.
4. **Оценка:** Выбрана модель XGBoost как лучшая по балансу точности и полноты (Recall).

## 📈 Результаты
| Модель | ROC-AUC | Recall (Churn) |
|--------|---------|----------------|
| Logistic Regression | 0.8625 | 0.55 |
| XGBoost | **0.8586** | **0.54** |
